# Video Lap Tracking Lab

Das [Video Lap Tracking Lab](pathname:///vltl/) (VLTL) läuft direkt im Browser. FPV-Video öffnen, jede Runde Bild für Bild markieren, und das Tool zeigt die beste Einzelrunde sowie die drei besten Runden am Stück. Nichts wird hochgeladen: Das Video bleibt auf dem eigenen Rechner.

<a className="button button--primary" href="pathname:///vltl/" target="_self">Lap Timer öffnen</a>

## Anleitungen

- [Rundenzeit-Overlay für DaVinci Resolve](./resolve-guide.mdx): Ein Skript aus dem Lap Timer kopieren und Live-Rundenzeiten direkt ins Video bringen, dazu die HDZero- und Betaflight-OSD-Schriftarten.
