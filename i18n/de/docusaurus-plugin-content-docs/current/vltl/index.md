# Video Lap Tracking Lab

Das [Video Lap Tracking Lab](pathname:///vltl/) (VLTL) läuft direkt in deinem Browser. Öffne dein FPV-Video, markiere jede Runde Bild für Bild, und schon zeigt dir das Tool deine beste Einzelrunde sowie deine drei besten Runden am Stück. Nichts wird hochgeladen – das Video bleibt auf deinem Rechner.

<a className="button button--primary" href="pathname:///vltl/" target="_self">Lap Timer öffnen</a>

## Anleitungen

- [Rundenzeit-Overlay für DaVinci Resolve](./resolve-guide.mdx): Kopiere einfach ein Skript aus dem Lap Timer, und du bekommst Live-Rundenzeiten direkt in dein Video, dazu die HDZero- und Betaflight-OSD-Schriftarten.
